Keep it
simple.

A focused task runner with local rooms. Host a room on your private network so nearby TaskRunner users can connect without using the internet.

Download beta How LAN works
01 / Host

Start a room

Use one computer as the host. Keep TaskRunner open, then share its local address, room key, and password.

02 / Join

Connect nearby

Use this when both computers are on the same Wi-Fi or wired network. Probe the host, then join the room.

03 / Finish

End the host

End Host when the session is finished. Closing TaskRunner on the host computer also ends the room.

Network help

Know what to check.

Open Signal Lab when a room cannot be found, a peer will not join, or syncing feels slow.

CAN'T FIND THE ROOM

Discovery

Confirm both computers are on the same router and the host is still running.

BEFORE JOINING

Probe Host

Test the host address and room details before opening the full room.

SYNC FEELS SLOW

Network Health

Check Discovery, Host, Peers, and Sync to see which part needs attention.

STILL NOT WORKING

Diagnostics

Run the checks and copy a safe report without including the room password.

Fast connection check: keep the host open → use the same local network → allow TaskRunner through Windows Firewall → run Probe Host.
